# BTC 판단 시간봉: 15분봉 제외

## 지시와 범위

2026-10-23 사용자 정정: **15분봉은 타이밍 보조로도 사용하지 않는다. 최소 분석봉30분,중요도1시간>30분>4시간>12시간>일봉>주봉이다.** M3/M4 판단자료·응답 계약 변경이며 수익성 입증이 아니다. 기준선은f6410e52다.

수렴장 전면 진입 금지·추가 종가/재시험 대기·고정RR·새부분SL비율은 추가하지 않는다. 강한 돌파 참여와30분이상 형성중 관측은 유지한다. 기존 위험·보호·FAILED 전량EXIT·Sol low·5분판단/1분보호 주기는 그대로다.

## 입력 경계

21:15 원 입력의15분 확정하락·2.990466배 거래량이 진입 근거로 쓰였다.15분 거래량 가속도와동일진행률 프로필은30분·1시간등에도 복제돼 있어 원봉만 지워서는 부족하다.

`scenario_analysis_frames.py`의 판단전용 복사뷰를 single/DRAFT/SELECT에서 공유한다. 원timeframes.15m,ma_structure primary/timing,current_primary_frame_facts,entry_display,recovery숫자경로/변화근거·응답enum과신규goal범위를 제한한다. 다른 시간봉에 복제된volume_acceleration·same_progress_profile도 제외한다.15분만의 변화로새PROBE허가가 열려서는 안 된다.

## 보존과 예외

- 원수집·snapshot/context·감사테이프·체결/회계·receipt는 변경하지 않는다. 의도적 판단뷰 제외와 손실없는 입력압축은 서로 다른 단계다.
- 전역TIMEFRAME_MS,legacy numeric_market와v1~v7 decoder는 기존자료를 계속 복원한다.
- 신규OPEN의15m목표는 schema와host수용에서 거절한다. 기존15m계약ID·고정가격·실패규칙은 불변 역사적 보호정보로 보존하되 현재15m신호로 재사용하지 않는다.
- 명시적15m/15분봉을 인용하는 과거 의견은 모델뷰에서 의견전체를 값없는생략표시로 구분한다. 문자열 일부만잘라숫자를오귀속하지 않는다. 이표시처리는주문/EXIT veto가 아니다.
- 기존 수집기의 품질·신선도·유효성 검증은 유지한다.15분원자료 수집자체가없어졌다거나 수집실패 종속성이없다고 주장하지 않는다. 원valid=false를 임의로true로바꾸지 않는다.
