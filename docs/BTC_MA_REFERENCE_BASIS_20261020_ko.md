# 현재가와 예정 진입가의 MA 위치 구분 (M3/M4 설명 수리)

## 구현 전 검토

1. **범위/기준선:** `90f9ccf4`의 공통 MA 설명 지침만 보완한다. 2026-10-19
   23:10 slot5974730의 미채택 SHORT 후보가 4h/12h MA10을 현재가 위·이미 지난 수준으로
   설명했다. 최종 SELECT는 하방 반응을 언급하며 WAIT였고 주문은 없었다.
2. **원인 증거:** 당시 Mark81,911.6/Last81,915.6보다 4h MA10 확정81,857.85,
   형성81,904.7 및 12h 확정81,836.77/형성81,864.07 모두 낮다. 실제 MODEL_REQUEST의
   keyed row-table에 음수 distance_price와 relative_to_mark=BELOW, 현재 Mark reference,
   short_downward_obstacles가 정확히 담겼다. DRAFT98,287B/SELECT97,889B이며 lossless
   복원도 정확하다. 계산·전송 누락은 확인되지 않았다. 예정 진입81,690/트리거81,700보다
   MA가 높은 것과 현재가 기준을 혼동했을 가능성이 있지만 모델 내부 인과는 미확정이다.
3. **호환/권한:** snapshot→MA facts→lossless projection→SINGLE/DRAFT/SELECT→호스트
   검산/실행 경로를 유지한다. 현재 LEVEL 대 Mark와 예정 진입의 가정적 경로를 구분하고,
   SELECT도 후보 설명보다 현재 구조화된 팩트를 대조한다. 모든 MA 나열이나 별도 검증
   호출을 요구하지 않는다. 모델·데이터·schema·100KB 한도·위험·SL·FAILED 권한은 불변이다.
4. **판정 기준:** 사건의 네 MA 값/부호/ID, LONG 반대 방향, EQUAL, Mark/수준 결측,
   확정/형성 straddle, 두 단계 전달·복원·현재 facts 보존을 오프라인 검증한다. 원문
   DRAFT/SELECT 재투영과 user payload byte 동일성을 별도 확인한다. 실제 모델 비교는
   고정 원문 두 단계×전후 각1회이며 원래 잘못된 후보도 SELECT 입력에 그대로 보존한다.
5. **중단/후속:** 테스트·CI·배포·첫 자연 판단과 재발 여부를 분리한다. 설명 재발 가능성은
   남으며 이 한 사례로 전역 거래 차단·전략·위험 규칙을 만들지 않는다. 회귀가 발생하면
   해당 프롬프트 변경만 복귀를 검토한다. 20:35 트리거 설명 차이는 이번 범위 밖이다.
6. **결론:** 사용자 승인된 설명/근거 연결 수리다. 실제 주문·손절 실패나 잘못된 SELECT
   영향은 입증되지 않았으며, 모델 정확도 일반화·수익 개선·M5 입증으로 해석하지 않는다.
