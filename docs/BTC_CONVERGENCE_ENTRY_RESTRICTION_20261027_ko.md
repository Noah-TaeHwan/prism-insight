# 두 시간프레임 동시 수렴 시 신규 진입 제한

## 1. 변경 유형과 기준선

2026-10-27 사용자가 **1시간·30분 확정봉이 모두 수렴할 때만 제한**하도록 선택했다. M4 진입 정책 변경이며 기준 소스는 69a53b7e다. 위험 한도·레버리지·보유 포지션 보호는 유지한다. 사용자 승인 거래 범위를 구현하는 변경이며 M5 수익 개선 입증은 별도다.

## 2. 가설과 판정 정의

각 시간프레임의 최근 두 확정봉에서 절대 MA10–MA35 간격이 모두 줄면 신규 진입을 제한한다. 간격이 좁다는 사실만으로 수렴으로 판정하지 않는다. 형성 중인 봉의 순간 돌파로 제한을 해제하지 않는다.

1시간이 수렴하더라도 30분이 발산하면 추세 초기일 가능성을 검토할 수 있도록 기존 판단을 허용한다. 자동 진입 신호는 아니다. 양쪽 입력이 확인되어야 하며 누락·오래된 값·표기와 실제 간격의 불일치는 UNKNOWN으로 남기고 신규 진입을 허용하지 않는다.

## 3. 적용 경로와 보존할 기능

시장 snapshot → 공용 수렴 판정 → 모델 입력/검산 → 최종 승인 → 저장된 승인 근거를 재검사하는 주문 경로에 같은 기준을 적용한다. 실제 CLI와 economic-reject-goal-v2 재생에서 켠다. 기존 재생 프로필은 유지한다. 프롬프트의 설명과 호스트의 판정은 동일한 사실을 사용한다.

OPEN, ADJUST의 신규 entries, 미체결 예약 갱신을 제한한다. 동시 수렴이 다음 정기 판단에서 확인되면 기존 미체결 진입도 호스트의 취소 전용 WAIT로 취소한다. 취소 접수를 완료로 처리하지 않으며 실제 증거가 나올 때까지 예약과 위험을 보존한다. 기존 보유의 손절 보호·보호 강화·REDUCE·EXIT는 계속 허용한다. 수렴만으로 보유를 강제 청산하지 않는다.

주문 경로는 승인 당시 원본 snapshot을 재검사한다. 거래소에서 실시간 이평선을 감시하는 기능은 아니다. 다음 정기 판단 이전 또는 취소 처리 중 체결될 가능성은 남으며 실제 체결에 대한 보호를 유지한다. 신규 승인 직전 120초 신선도와 다음 30분 경계를 검사한다.

## 4. 검증과 해석

확정 간격의 축소/확대/동일 9개 조합, LONG/SHORT, 음의 이평선 순서, 형성봉 충돌, 자료 누락·오염·시간 경계, 신규/추가/갱신, 보호 전용 변경을 검증했다. 실제 runtime/broker와 격리 거래소를 연결한 미체결 취소 및 일부 체결 후 나머지 취소에서도 보유·손절을 보존한다. 위조된 승인 근거는 거부한다.

최근 최종 관련 검사 118개가 통과했다(수렴 정책·runner·calculated runner·provenance). 별도 관련 실행 검사 217개 및 runtime 검사 120개도 통과했으며 서로 중복되므로 합산하지 않는다. 전체 검사는 PR CI에 맡긴다.

최근 22개 완료 거래 중 동시 수렴 대상은 7건이다. 오늘 09:11 LONG은 제한 대상이지만 08:06 SHORT는 대상이 아니다. 정책 버전 7개가 섞인 표본이므로 이는 적용 범위 점검이다. 두 손실을 모두 방지한다거나 수익이 개선됐다고 해석하지 않는다. 방향상 동시 수렴 진입을 줄이면서 30분 발산의 진입 기회를 남긴다.

기존 연속 2시간 실험은 수정 전 기준선이다. 24개 판단 구간을 완료했지만 완료 거래 0건·미청산 LONG 1건으로 승률·평균 이익·평균 손실·손익비는 산출할 수 없다. 미청산 평가손익 +1.508832 USDT를 확정 수익이나 이 변경의 효과로 보고하지 않는다. 이번 구현의 추가 유료 모델 호출은 0회다.

## 5. 관측·중단·복귀

신규 위험 억제, 예약 우회 방지, 기존 보호/청산 지속을 먼저 확인한다. 수렴 해제 후 진입 재개와 놓친 기회·완료 거래·비용·낙폭은 별도로 관측한다. 관련 회귀나 정확한 PR head의 CI가 실패하면 배포하지 않는다. 위험 예산 확대·실자금·추가 상주 배치는 범위 밖이다.

## 6. 상태

사용자 기준 확정과 구현·관련 로컬 검증을 완료했다. CI·데모 배포·첫 정기 실행·수익성은 각각 별도 증거가 필요하며 이 문서 작성 시 아직 완료로 처리하지 않는다.
