# 모델 입력에서 호스트 전용 실행 이력 제외 (M0)

## 문제

100,000바이트는 모델 컨텍스트 한도가 아니라 UTF-8 요청 본문에 대한 자체 상한이다.
`seen_action_ids`는 모든 처리 주문 ID를 담아 누적되며, 현재 모델용 문맥에도 그대로 전달된다.
고정한 자연 판단의 336개 ID는 키 포함 9,786바이트를 차지한다.

## 변경

- 단일 판단 및 DRAFT·SELECT의 모델용 문맥 복사본에서 `seen_action_ids`만 제외한다.
- 원본 문맥, DB 이력, 호스트의 `duplicate action` 검사, 검토 시 신선한 상태 대조는 유지한다.
- 모델이 출력할 ID는 기존 응답 schema의 고정 enum을 따른다. ID 생성 방식은 바꾸지 않는다.
- 시장·포지션·수량·손익·진입 전제·보호 자료와 과거 입력 decoder는 변경하지 않는다.
- 입력 100KB 및 판단 시간 제한은 그대로 둔다. 새로운 압축 형식이나 의존성은 추가하지 않는다.

## 검증 범위

먼저 비어 있지 않은 이력이 모델 입력에 남는 회귀를 재현한다. 이후 단일 판단·DRAFT·SELECT,
보유·예약 상태에서 원본 불변과 출력 schema 동일성을 확인한다. 이력 증가가 모델 입력 크기를
늘리지 않는지, 호스트 중복 실행 거부가 여전히 동작하는지도 검사한다.
최종 테스트·CI·배포·자연 판단 확인은 별도로 기록한다. 입력 경량화는 수익성 증거가 아니다.
