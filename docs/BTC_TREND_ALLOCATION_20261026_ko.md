# M4 추세 익절 배분 조정

2026-10-26 사용자 승인: 기존 구조를 유지하며 손익비를 튜닝하고 Bybit 데모에 배포한다.

1. 경제적 판단 변경이다. origin/main을 기준으로 공통 판단 프롬프트의 50/30/20 출발점만 교체한다. 이전 #1132 후보는 누적하지 않는다.
2. 가설: 밴드 밖의 근거 있는 추세에서 가까운 목표에 기본 절반을 배정하는 앵커를 제거하고 반응·실패 위험에 따라 비중을 정하면, 같은 진입·구조적 손절에서 큰 이동에 참여하는 물량과 경로 손익비가 개선될 수 있다. 반응 위험이 강하면 가까운 비중 확대가 여전히 타당하다.
3. 경로: scenario_llm.SYSTEM_PROMPT → scenario_calculated_review DRAFT → 호스트 수량/경로 계산 → SELECT → review_guard → runtime/broker → 후속 WAIT/ADJUST/EXIT. 공통 배분 지침 한 계층만 변경한다. 호스트 계산·선택 권한·진입 관문·위험·레버리지·보호·목표 불변성은 유지한다. MA10→MA35 제한 횡단에 추세 잔량을 강요하지 않는다.
4. 기존 동결 밴드 안/밖 LONG/SHORT 4개 개발 입력으로 기준/후보 실제 모델 비교 최대16 HTTP·retry0. 이전 호출 장부를 재사용하지 않는다. 같은 진입·SL·TP 가격·진입 배분의 기존 계획에 후보 TP 비중만 대입한 호스트 계산을 별도로 대조한다. 반례: 가까운 반응대·약한 추세·제한 횡단·최소수량·보유 잔량. 독립 holdout·실제 승률·실현 수익성은 미입증이다.
5. 사전 기능 기준: 실제 응답/호스트 검사 통과, 밖 LONG/SHORT에서 동일 가격 기준 배분의 비용 가정 TP_STOP/STOP 비율 비악화 및 최소1개 개선, 근거 없는 목표/손절 조작·원 목표 변경·반응대 무시·강제 러너 없음. 기술 오류/핵심 의미 오류면 배포 보류한다. 기계적 손익비 floor나 승률을 새로 만들지 않는다. 자연 관측에서 정책 모순·보호 회귀가 확인되면 이 문단 변경을 PR로 되돌린다. 결과를 보고 기준을 완화하지 않는다.
6. 이번 승인은 제한적 데모 정책 튜닝이며 M5 수익성 입증이 아니다. 배포 전 관련 테스트·정확한 head의 모든 CI, clean ff-only 배포·스모크와 첫 정기 실행을 각각 확인한다. 기존 주문정체 24시간 관측은 별도 유지한다.

## v1 개발 결과와 v2 사전 등록

v1은14 HTTP(남은2 봉인),8개 기술 통과다. 동일 가격·위험에서 후보 비중만 적용한 가정 비용 경로 비율은 밖 LONG0.2022→0.3149, SHORT0.4476→0.5930으로 개선됐다. 다만 SHORT 실제 초안/선택이 첫 목표 앞84082 저가대를 설명 없이 넘겨 의미 검토 HOLD다. 첫 익절 이후 반전 경로는 더 불리할 수 있으며 수익 개선 판정이 아니다.

v2는 같은 배분 문단에 “비중 변경만으로 첫 목표를 더 멀리 옮길 근거가 되지 않으며, 앞의 반응대와 통과 근거를 명시한다”는 세 줄만 보완한다. 다른 계층을 수정하지 않는다. v1 기준안 네 응답을 해시로 고정해 재사용하고 같은 네 입력의 v2 후보만 최대8 HTTP·retry0으로 비교한다. v1 장부는 재개하지 않는다. 앞의 기능 판정 기준을 그대로 적용하며, 부족한 쌍은 MISSING으로 남긴다. 이미 본 개발 자료이므로 독립 검증이나 통계적 수익 개선으로 표현하지 않는다.
