# BTC 가까운 부분익절과 비용 해석 보완

## 변경 검토 (M3/M4, M5 미입증)

1. **변경 유형·기준선:** 2026-10-17 사용자가 승인한 경제적 판단 지침 변경이다.
   기존 500/700~800/1000달러 거리 중심의 예시를, 구조와 비용 여지가 있는 경우
   100~300달러 앞단 익절도 비교하는 재량 지침으로 바꾼다. 30배·전액 투입은 도입하지 않는다.
2. **가설·반증:** 짧은 파동에서 일부를 확보하고 잔량은 긴 추세를 추종한다.
   강한 추세에서 조기 익절이 이익을 줄이거나 비용 후 기대수익을 악화시키면 개선 가설은
   지지되지 않는다. 100~200달러의 유리한 이동 자체는 순수익 증명이 아니다.
3. **연결 궁합:** `live/scenario_llm.py`의 공유 SYSTEM → MA → 무포지션 부록이
   `live/scenario_calculated_review.py:research_review`의 후보와 선택 단계에 함께 전달된다.
   모델은 구조적 SL·TP·배분을 선택하고 호스트는 수량·위험을 계산한다. 가격·신선도·위험
   최종 검사와 기존 실행·보호는 유지한다. 50/30/20은 강제가 아닌 참고 비중이고,
   더 가까운 지지·저항 및 마디가격이 거리 예시보다 우선이다.
   `runner_economics.cost_positive_stop`의 보수적 비용 경계를 실제 손익분기점 또는 필수 SL로
   읽게 하던 문구는 제거한다. 기록 비용, 스트레스 여유분, 선택적 `fee_only_projection`을
   구분하며 LEG_ONLY를 전체 거래 순이익으로 부르지 않는다. 예상 비용은 미래 실비가 아니다.
4. **검증:** LONG/SHORT × 무포지션/보유의 실제 조립 프롬프트와 후보/선택 두 단계에서
   동일 지침 전달을 검사한다. 비용 미확인은 0이나 자동 관망으로 바꾸지 않는다.
   부분익절 승리와 전체 거래 승리, 실제 수수료와 위험 여유분의 혼동을 반례로 고정한다.
   독립 holdout·필요 표본·성과 비교는 이번 코드 검증에 포함되지 않으며 수익 개선은 미입증이다.
5. **관측·복귀:** 배포 후 최초 자연 판단의 입력·원응답·선택·최신 검사 기록을 확인한다.
   비용 오독·교차 TP·위험 우회가 발견되면 해당 변경의 중단/복귀를 검토한다. 단일 손익으로
   자동 복귀하거나 새 연구·모니터링 배치를 만들지 않는다. 통계적 관측 종료 시점은 미설정이다.
6. **현재 결론:** 사용자 승인 데모 변경의 구현/오프라인 검증 대상이다. CI·배포·최초 정규
   실행은 별도 증거가 필요하며 이 문서는 완료를 선언하지 않는다. 실자금·배율·한도는 그대로다.

## 프롬프트 논리 확인

- 구조/비용 여지 있음 → 가까운 부분익절 후보 비교. 고정 거리·고정 비중·필수 익절은 아니다.
- 부분익절 후 → 기록된 전체 순손익 + 잔량 가격손익 − 향후 가정 비용을 비교한다.
  이미 순액인 기록에서 비용을 다시 빼지 않고 즉시 본전 SL도 강제하지 않는다.
- 스트레스 계산이 음수 → 보수적 위험 진단일 뿐 실제 순손실 단정이나 감축 금지 사유가 아니다.
- 수수료 근거 없음 → 미확인 유지. 임의의 0이나 거래 차단 명령으로 만들지 않는다.
- 강한 추세 → 잔량의 더 먼 목표를 검토한다. 모든 물량의 첫 TP를 멀리 미루지는 않는다.
- 호가 근거 없음 → 유동성을 지어내지 않는다. 방향별 지지 위/저항 아래 배치도 체결 보장은 아니다.
