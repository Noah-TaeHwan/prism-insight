# 지식 흡수 하네스 (책·외부 지식 → PRISM)

사용자가 읽는 책이나 외부 자료의 지식을 PRISM의 북극성(`docs/HARNESS_CORE_ko.md`)에 맞게 **가공해서** 영구적으로 남기는 곳이다. 미래 세션(Claude·Codex)은 지식을 찾을 때 이 폴더부터 본다.

## 왜 가공하는가
책의 주장을 그대로 시스템에 넣으면 모순과 노이즈가 생긴다. 포켓피봇 연구(2026-09-30~10-26)에서 실제로 겪은 일이다.
- 책은 "10일선에서 빨리 팔고 PP로 다시 사라"고 한다. 우리 주도주 보유 규칙(R5)은 "크게 가는 종목은 오래 든다"다.
- 책의 "이상적인 맥락"(거래가 마른 빡빡한 베이스)은 우리 데이터에서 오히려 나빴다.
- 책의 "7주 규칙"은 우리 실제 거래에서 적용 대상이 없었다(KR 0/202, US 1/134).

그래서 지식은 **주장 → 북극성 대조 → 우리 데이터 증거 → 가공된 결론** 순서로 카드에 남긴다.

## 구조
| 경로 | 내용 |
|---|---|
| `INDEX_ko.md` | 모든 카드의 한 줄 색인(ID, 주제, 태그, 북극성 적합도, 증거 상태, 결론). **먼저 여기서 찾는다** |
| `books/<책-슬러그>/SOURCE_ko.md` | 쪽 범위별 요약(원문을 길게 옮기지 않는다. 공개 저장소이므로 짧은 인용과 요약만) |
| `books/<책-슬러그>/CARDS_ko.md` | 그 책에서 뽑은 지식 카드 |
| 절차 | 스킬 `skills/prism-knowledge-intake/SKILL.md` |

## 카드 양식
```
### K-<영역>-<번호> 제목
- 출처: 책, 쪽 (+ 그림 번호)
- 주장(요약): 책이 말한 것. 해석이 애매하면 "애매"라고 적는다
- 유형: 규칙(책이 명시) / 이상형("가장 좋다", "바람직") / 사례 / 주의 / 운용 방식
- 적용 범위: 어떤 유형·국면·종목에 대한 주장인가(예: 지속형 PP 전용)
- 북극성 적합도: 도움 / 중립 / 충돌 — 이유 한 줄
- 우리 시스템 위치: 해당 계층과 파일(스크리닝·BUY·게이트·사이징·SELL·재진입)
- 증거 상태: 미검증 / 검증 중 / 채택 / 기각 / 적용 대상 없음 / 이미 반영 / 범위 밖 — 근거 링크(연구 폴더, RESEARCH_LESSONS, 가설 ID)
- 가공 결론: 우리 시스템에 어떤 형태로 남기나(또는 남기지 않나)
- 갱신: YYYY-MM-DD
```
- 정정이 생기면 **카드를 덮어써서 최신 판정만 남긴다**. 이력은 git이 보관한다. 틀린 옛 문장을 남겨 두지 않는다.
- 카드는 매매 규칙을 직접 바꾸지 못한다. 매매 변경은 반드시 `prism-trading-change-review`(하네스)를 거친다.

## 증거 상태 용어
- **채택**: 사전 등록한 검증에서 통과했고 운영에 들어갔거나 들어갈 예정
- **기각**: 사전 등록 검증에서 우위가 없었다(같은 셋업 대비, 무작위 대비)
- **적용 대상 없음**: 규칙은 맞을 수 있지만 우리 종목·거래에서 발동하지 않는다
- **이미 반영**: 같은 내용이 이미 우리 시스템에 있다
- **검증 중 / 미검증**: 아직 판단 근거가 없다. 탐색적 분해 하나는 "확인"이 아니다
- **범위 밖**: 우리 유니버스·구조에서 다루지 않는다(예: IPO, 레버리지)

## 흡수할 때 지키는 교훈 (포켓피봇 연구에서 얻음)
1. 책의 "이상형"을 숫자 게이트로 만들지 않는다. 책 사례조차 탈락한다(정답지 0/9). 게이트는 책이 규칙으로 명시한 것만 둔다.
2. 규칙이 **어느 유형·절의 규칙인지** 확인한다. 229쪽 10일선 과열 규칙은 지속형 PP 전용이었다.
3. 책 사례는 성공한 주도주 위주의 사후 선택이다. 우리 시장 전체에서 우위가 있는지는 따로 검증한다.
4. 고정 % 손절로 비교하면 변동성 낮은 후보군이 유리하게 보인다. ATR로 정규화한다.
5. 탐색적 분해 하나(칸당 수십 건)를 "확인"이라 부르지 않는다. 역할이 바뀌면 뒤집힌다.
6. 손절은 **위치(구조)**와 **최대 손실(위험 한도)**의 위계가 있다. 구조는 한도 안에서만 쓴다.
7. 책은 방향과 구조만 주고, 구체 수치는 시장별로 우리 데이터에서 정한다(사용자 원칙, 2026-10-22).
