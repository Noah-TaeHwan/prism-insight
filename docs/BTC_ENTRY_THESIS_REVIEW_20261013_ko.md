# 진입 근거와 체결 후 가격 진행 연결 · 2026-10-13

## 승인·방향·단계
사용자는 진입 후 근거가 약해지면 정리하도록 프롬프트·로직 보완과 데모 배포를 명시적으로 승인했다. M3 입력 증거 연결과 M4 보유 판단 정책 변경이다. M5 수익성 입증이나 실패한 짧은 TP 후보의 승격이 아니다. 실자금·모델·배율·위험 한도·SL/TP 가격 공식은 변경하지 않는다.

## 도입 검토
1. 목적: MA 방향은 같지만 해당 돌파 진입의 가격 진행이 실패한 경우, 원래 근거를 보유 판단에서 다시 평가한다.
2. 대상: 현재 시나리오의 확인된 진입 체결이 있는 보유 문맥. 미체결 예약을 체결로 간주하지 않는다.
3. 대안: 기존 유지/문구만 추가/정해진 분수 뒤 자동 손절/숫자 증거 연결을 비교했다. 문구만 추가하면 최초 주문이 후속 ADJUST에 가려지는 문제가 남고, 자동 시간 손절은 정상 재시험을 자를 수 있어 채택하지 않았다.
4. 변경 계층: 기존 broker context에 읽기 전용 entry_thesis를 더하고 LLM 보유 판단의 우선순위를 명료화한다. 호스트 강제 청산 규칙이나 중복 점수·게이트를 추가하지 않는다.
5. 궁합: 확인된 OPEN·entry children·execution → broker context → runtime 결정 입력 저장 → 모델용 무손실 변환 → 기존 LLM → 기존 출력/가격/위험 검증 → 기존 실행/보호. 기존 조건부 감축·EXIT만 사용하며 즉시 부분 시장가 청산을 발명하지 않는다.
6. 성공 범위: 원본 진입 연결·불명확한 자료 처리·정상 눌림 반례·실제 모델의 기존 계약 준수·배포 후 자연 실행을 각각 검증한다. 손실 감소나 수익 개선은 별도 비교 전까지 미입증이다.

## 입력의 의미와 한계
최초 OPEN의 동일 scenario/side/action과 실제 체결 entry child를 연결한다. 주문 limit/조건부 trigger는 실제 제출 요청에서 읽고, 확인된 최초 체결·진입 수량·초기 체결 평균·최종 추가 체결 시각과 현재 Mark의 비교를 제공한다. 후속 ADJUST의 비어 있는 entries가 원래 진입을 덮지 않는다. 추가 진입이 최초 체결 시계를 초기화하지 않는다.

이 정보는 현재 두 시점의 비교이며 연속 경로·MFE/MAE·잔여 lot 원가·진입 당시의 전체 시장 판단을 복원하지 않는다. trigger는 진입 활성화 조건이지 자동 손절선이 아니다. 원래 setup 유형이나 기대 보유시간이 저장되지 않았으면 추정하지 않는다. 과거 rationale은 모델에 다시 넣지 않는다. 불완전·모순·미래 시각은 MISSING으로 처리하고 기존 보호는 유지한다.

## 프롬프트 논리
기존의 정상 눌림 유지·holding≠fresh-entry 원칙은 유지한다. 다만 넓은 MA 방향과 개별 진입의 유효성을 구분하며, 실제 실패 근거가 있으면 본전·기존 SL·후행 교차를 기다리기보다 EXIT/적법한 조건부 감축을 검토한다. 불리한 진입 상대 진행에도 WAIT하면 지금 보유를 지지하는 근거와 실패 조건을 설명한다.

반대로 trigger 한 번 회복·한 틱·최근 체결·시간 경과·천천히 나오는 유리한 움직임만으로 EXIT하지 않는다. 구조적 반례와 현재 제공된 15분 이상 가격 경로를 함께 판단한다. 롱·숏 대칭이며 최소 시간프레임·상위 이평 장애물 참고는 같다. 새 TP 프레이밍과 비용 충당금 수정은 이번 범위 밖이다.

## 검증 기준과 반례
- 미체결·부분 체결·추가 진입·일반 LIMIT·조건부 LONG/SHORT를 구분한다.
- sid/side/action/체결 ID·수량 불일치, 중복·미래·비정상 수치·너무 큰 입력을 검사한다.
- 건강한 retest, 최근 체결, 느린 유리한 진행, 부분익절 잔량에서 자동 EXIT가 생기지 않는지 검사한다.
- 입력은 작게 제한하고 새 API·DB 쓰기·모델 호출을 추가하지 않는다. 누락은 보호 중단 사유가 아니다.
- 실제 모델 진단은 별도 사전등록·원본 문맥·고정 호출 상한으로 수행하고, 주문·운영 DB 쓰기 없이 규격·위험·판단 근거를 확인한다. 사후 가격과 계좌를 과거 입력으로 넣지 않는다.
- 전체 BTC 오프라인 테스트, CI, 서버 격리 테스트, import smoke, 첫 자연 5분 판단을 분리한다.

## 상태
로컬 전체 회귀 3,466개 통과·12개 skip, 실제 모델 A/B 16회 출력·가격·위험 검사 통과를 확인했다.
후보는 WAIT 7회·ADJUST 1회·EXIT 0회다. 지속 역행 숏에서 SL83,080→82,930을 제안했고
최근 체결·정상 재시험·느린 유리한 진행은 유지했다. 단일 개발 사례 진단이며 수익 개선이나
즉시 청산 행동의 보편적 입증은 아니다.

설명 의미 검증에는 후보3건의 예외가 남았다. 비용 양수 SL과 Mark의 상하 설명이 반대인
1건, MA와 TP의 선후 설명 오류1건, 적용 가능한 수익 보호선을 유지하지 않은 구조적 이유
누락1건이다. 실제 제안 가격·위험은 검증을 통과했으나 설명 정확성까지 통과로 표시하지 않는다.
원응답은 보존하고 이 오류를 숨기려고 다시 뽑거나 등록된 실험을 바꾸지 않았다. 숫자 관계 설명과
보호 이유의 별도 보완 과제로 남긴다. 최초 OPEN은 미체결이고 후속 ADJUST만 체결된 경로에서는
새 진입 근거가 MISSING일 수 있다. 원래 보호·보유 판단은 유지하며 가짜 근거로 채우지 않는다.

CI·서버 격리 검증·배포·첫 자연 실행은 해당 PR 및 배포 영수증에서 각각 확인한다.
M5 수익 개선은 여전히 미입증이다. 실패한 짧은 TP 연구 후보는 이번 변경에 포함하지 않았다.
