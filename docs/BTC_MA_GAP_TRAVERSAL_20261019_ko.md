# 발산 중 MA10→MA35 공간 진입 (M4)

## 구현 전 검토와 판정 기준

1. **변경 유형·기준선:** `ec78923c`의 정성 판단 계층만 바꾸는 경제적 의사결정 변경이다.
   사용자는 발산이 여전히 진행 중일 때 가격이 MA10을 넘어 MA35 방향으로 움직이는
   별도 후보를 승인했다. 실행·위험·모델·일정·확정 실패 규칙은 바꾸지 않는다.
2. **가설·반증:** LONG은 MA10<MA35에서 가격이 MA10 아래→위의 두 선 사이로 상승하고,
   SHORT는 MA10>MA35에서 MA10 위→아래의 두 선 사이로 하락하는 경로다. 간격이
   계속 WIDENING이어도 가능하다. 수렴·발산 정점·배열 역전·완전한 추세 전환·MA35
   선행 접촉/거절·추가 확정봉/재시험을 요구하지 않는다. 폭이나 발산 부호만으로는
   부족하다. 가격 진행 소멸·역행·가까운 장애물·비용 후 여유 부족은 반례다.
3. **궁합·권한:** snapshot의 own-time ma_path → 기존 MA 문맥 → 공통
   MA_STRUCTURE_PROMPT(SINGLE/DRAFT/SELECT) → 기존 호스트 경제 검산 → 실행/보유
   경로를 유지한다. 기존 MA35 반응 뒤 추세 재개 후보를 대체하지 않는다. 국소 MA10
   경계 돌파는 기존 BREAKOUT regime으로 표현하며 전체 추세 전환을 뜻하지 않는다.
   원래 premise/expected_progress에 제한된 MA35 방향 목표를 기록하고 기존 numeric
   explicit_failure가 유일한 수치 실패 규칙이다. 보유 계약 재분류·실패 후 목표 확장은 금지한다.
   전역 1h>30m>4h 순서는 유지한다. 이 후보의 구조 신뢰도는 1h/4h 근거를 30m보다
   중시하되 AND 조건으로 묶지 않는다. 30m 보조·15m 타이밍이며 4h 부재는 UNKNOWN이다.
   higher_frames의 최신 수준만으로 경로를 만들지 않는다. 원본 snapshot의 4h ma_path는
   이미 공급되며 추가 입력 필드/수집/엔진은 필요 없다. KR/US는 대상이 아니다.
4. **사전 검증:** 롱숏·확정/형성 대칭, 실제 WIDENING 경로 전달, MA만 움직인 가짜 돌파,
   4h 누락·미래시각·상위 장애물, 기존 실패 계약/레거시 보유 보존을 오프라인 회귀로
   확인한다. 전체 BTC suite·정확한 head CI와 주문 없는 고정 입력 실제 모델 비교를
   별도 확인한다. 합성 사례는 체결·승률 표본이 아니며 비용·체결 계산은 기존 호스트가 맡는다.
5. **유지·중단·복귀:** 전후 버전/당시 입력을 보존해 구조 변경과 시세·실행 오류를 구분한다.
   판단 입력 모순·위험/계약 회귀가 발생하면 기준선 복귀를 검토한다. 진행 포지션 보호와
   원래 계약은 보존한다. 최근 손익만으로 자동 왕복하지 않는다. 운영 첫 자연 판단 이후
   2주 점검에서 등록 후 자료를 검토하되, 비용 후 성과·holdout·표본은 기존 M5 기준을
   따른다. 자료가 부족하면 INSUFFICIENT이며 기존 종료 A/B 연구는 재시작하지 않는다.
6. **현재 결론:** 사용자 승인된 Bybit 데모 후보 검토이며 실자금·새 SHADOW 활성화·
   수익 개선 입증이 아니다. 구현/오프라인/실제 모델/CI/배포/자연 판단을 각각 기록한다.

## 보유 시 해석

새 OPEN에서도 일반 러너/배분 기본값보다 이 후보의 제한된 목적이 우선한다. MA35 또는
더 가까운 실제 장애물까지의 청산안을 비교하고, MA35 너머 지속을 가정해 기대이익이나
원거리 러너를 정당화하지 않는다. MA35 정확한 가격·고정 배분·접촉 즉시 청산을 강제하지 않는다.

원래 공간 이동의 목적과 구조적 무효화를 유지한다. MA35 목표 도달/거절 또는 진행 실패를
근거 없이 큰 추세 전환·기존 추세 재개로 바꿔 계속 보유하지 않는다. 도달/터치는 자동
FAILED 판정이나 즉시 청산 명령이 아니며 기존 TP·검증된 잔량·비용·WAIT/ADJUST/EXIT와
보호 권한으로 관리한다. 원래와 다른 거래는 먼저 완전히 정산된 flat 뒤 새 판단 대상이다.
이 변경 이전 포지션이나 레거시 계약을 새 후보로 소급 분류하지 않는다.
